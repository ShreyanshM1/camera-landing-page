# Camera Landing Page 📸

A modern and responsive **Camera Landing Page** built using **HTML5** and **CSS3**. This project focuses on creating an attractive user interface with clean layouts, typography, and responsive design techniques.

## 🚀 Features

- Modern landing page design
- Responsive layout
- Navigation bar
- Smooth hover effects
- Clean and organized UI


## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Camera-Landing-Page/
│── index.html
│── style.css
│── assets/
└── README.md
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open `index.html` in your preferred web browser.
